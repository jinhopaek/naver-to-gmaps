네이버 지도 목록을 구글지도로 옮기는 크롬 확장

백진호2026년 11월 v0.6.1 시제품github.com/jinhopaek/naver-to-gmaps

구글지도 저장 목록에는 파일 가져오기 기능도 공개 API도 없다. 네이버 지도에 모아 둔 장소를 옮기려면 한 곳씩 다시 검색해서 저장하는 수밖에 없었다. 이 확장 프로그램은 네이버 공유 링크를 받아 그 반복을 브라우저 안에서 처리한다. 외부 서버를 거치지 않고 비밀번호도 받지 않는다. 사용자가 로그인해 둔 브라우저에서 사람이 하던 클릭을 순서대로 실행할 뿐이다.

만들면서 정한 것

  1. 저장 경로

    마이맵 KML로 시작했지만 저장 목록과 따로 노는 지도라 앱에서 쓰기 불편했다. 화면 변화에 약한 점을 감수하고 브라우저 자동화로 옮겼다.

  2. 입력은 링크 하나

    CSV 없이 공유 링크만 받는다. 네이버가 확장 프로그램의 요청을 403으로 막아서 그 요청에만 Origin 헤더를 바꿔 보낸다.

  3. 속도와 차단

    시험용 일부 저장 옵션은 없앴다. 고정 대기를 화면 변화 감지로 바꾸고 장소 사이엔 1~2.5초 무작위 간격을 둬 로봇 확인을 피한다.

  4. 같은 이름의 가게

    초기엔 결과가 여럿이면 실패로 넘겼다. 지금은 결과 URL의 플러스 코드로 좌표를 구해 거리와 영업 상태로 고른다.

  5. 멈췄다는 신호

    기본 배지는 16px 아이콘에서 숫자가 안 보였다. 작업 중엔 아이콘 전체를 원으로 바꿔 남은 개수와 느낌표, 체크를 그린다.

  6. 실패 처리

    못 찾은 곳은 기록하고 넘어간다. 로그인이나 로봇 확인 문제일 때만 멈추고 '이어서'와 '실패만 다시 시도'로 복구한다.
