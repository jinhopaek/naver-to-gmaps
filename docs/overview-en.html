Copying Naver Map saved lists into Google Maps

Jinho PaekNovember 2026 v0.6.1 prototypegithub.com/jinhopaek/naver-to-gmaps

Google Maps has no file import or public API for saved lists, so moving places from Naver Map meant searching and saving each one again by hand. This Chrome extension takes a Naver share link and repeats those steps in the browser. It uses no outside server and never sees a password. It clicks through a browser where you are already signed in.

Decisions along the way

  1. Where to save

    My Maps KML import makes a separate map that is awkward in the app. Automation puts places in the real saved list but breaks if the page changes.

  2. One link in

    There is no CSV step. Naver answers extension requests with a 403, so the extension rewrites the Origin header on its own requests only.

  3. Speed and blocking

    Every run saves the whole list. Fixed waits became page-change checks, and places are spaced 1 to 2.5 s apart at random.

  4. Shops with the same name

    Early versions gave up on multiple results. Now each result's plus code gives coordinates, and distance and business status decide.

  5. Showing that it stopped

    Chrome's badge was unreadable on a 16 px icon. During a job the whole icon turns into a circle with the remaining count, a ! or a tick.

  6. Failures

    Unfound places are logged and skipped. Only sign-in or robot-check problems halt the run, and Resume or Retry failed continues it.
